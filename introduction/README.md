## Fundamentos de Python

- ¿Qué es Python?: es un lenguaje de programación interpretado, de alto nivel. Contiene sintaxis clara, es versátil, con una gran de comunidad, además es multiplataforma.

Para la estandarización de proyecto de python se usa:

- Snake case como convención
- La extensión de los archivos de python es .py

### Proyecto al final de la sección

```md
Proyecto Sugerido: Registro de Usuario

Objetivo: Crear un programa en Python que permita a un usuario registrarse ingresando su nombre, año de nacimiento, correo electrónico y contraseña. Luego, el programa procesará y mostrará la información de entrada de manera dinámica.
Requisitos del Proyecto:

    Entrada de Datos:
        Solicitar al usuario que ingrese:
            Su nombre
            Su año de nacimiento
            Su correo electrónico
            Su contraseña

    Procesamiento de Datos:
        Calcular la edad del usuario en el año 2050, basado en el año de nacimiento ingresado.
        Convertir la contraseña a una serie de asteriscos para ocultarla.

    Salida de Datos:
        Imprimir en la consola la siguiente información:
            "Nombre: [nombre]"
            "Email: [correo]"
            "Tendrás [edad] años en el 2050."
            "Tu contraseña es: [número de asteriscos]"

Ejemplo de Ejecución:

    Si el usuario ingresa:
        Nombre: Ricardo
        Año de nacimiento: 1995
        Correo: ricardo@correo.com
        Contraseña: gato

    La salida debe ser:

Code

Nombre: Ricardo
Email: ricardo@correo.com
Tendrás 55 años en el 2050.
Tu contraseña es: \*\*\*\*
```
